## Scope
`internal/scanner/files.go` used Linux-only `syscall.Stat_t.Ctim`, breaking local (darwin) build/test verification: `internal/scanner` and `internal/server` failed to compile. Introduce build-tagged `statChangeTime` helpers (linux/darwin/other). Non-goals: no change to Linux behaviour (deployment target), no other scanner changes.

## Contract
Linux amd64/arm64 behaviour must be byte-identical: ctime still comes from `st.Ctim`. Darwin and other platforms compile and return ctime from their platform record (darwin `Ctimespec`) or fall back to mtime.

## Acceptance criteria
- [x] `CGO_ENABLED=0 go build ./...` succeeds on darwin.
- [x] `CGO_ENABLED=0 go vet ./internal/scanner ./internal/server` passes.
- [x] gofmt clean for changed files.

## Architecture review
Alternatives evaluated: duplicating stat logic inline per site (worse), a portable `FileInfo` wrapper (unnecessary). Chosen smallest design: one helper per GOOS with build tags, single call site in `statTimes`.

## Decisions
Platform split is Go idiom for OS-specific stat fields; no external dependency.
