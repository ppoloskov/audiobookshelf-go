## Scope

The Go runtime has no implementation and returns the explicit 501 fallback. Non-goals: cover upload (`/api/items/:id/cover`) and author image upload are separate implemented routes.

## Decisions
- Characterization (2026-10-29, implemented via implementation agent gpt-6-luna): `POST /api/upload` has no route-specific middleware; runtime auth precedes dispatch. Requires active user with upload permission. Uploaded-file check first: missing files / invalid multipart → empty 400; missing field(s) → plain-text `400 Invalid request body`; missing library → plain-text `404 Library not found`; invalid folder → plain-text `404 Folder not found`; upload/library-access denied → empty 403. Podcasts use a title directory; other libraries use available author/series/title directories; names sanitized; same-name files overwritten; individual move failures ignored; response empty 200.
