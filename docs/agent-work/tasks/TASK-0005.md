## Scope
Characterize upstream `server/managers/ApiCacheManager.js` (registered as `this.router.get(/^\/libraries/, this.apiCacheManager.middleware)`, `server/routers/ApiRouter.js:68`) and decide whether the Go server must implement an equivalent response cache. Non-goals: Redis/distributed caching; no changes to any response bodies.

## Contract
Any behavioural difference must be recorded per the repository contract; this route candidate is middleware, so the comparison unit is observable responses to GET /libraries* requests under identical state.

## Characterization (source evidence)
- Middleware skips caching when query `sort=random` (`ApiCacheManager.js` middleware).
- Key: `JSON.stringify({user: req.user.username, url: req.url})` — per-user, full URL including query string.
- Hit: replays cached headers + status + body (`res.set(cached.headers); res.status(...); res.send(...)`). No cache-specific headers are added.
- Miss: wraps `res.send` to store `{body, headers, statusCode}`.
- TTL: 30 min applied ONLY to `/libraries/:id/personalized` URLs (`key.url.search(/^\/libraries\/.*?\/personalized/)`); other entries evicted by LRU (max 1000, 10 MB) or invalidation.
- Invalidation: `Database.init()` adds Sequelize hooks (afterCreate/afterUpdate/afterDestroy/afterBulkCreate/afterBulkUpdate/afterBulkDestroy/afterUpsert) for every model: high-churn models (`session`, `mediaProgress`, `playbackSession`, `device`) clear only `/libraries/:id/personalized`, `/libraries/:id/recent-episodes` and `/me()`-prefixed slices; all other writes clear the entire cache. Registered only in ApiRouter at mount `/api`, so it covers all GET `/api/libraries*` requests (regex prefix match, registration before the library routes).

## Decision
Do NOT implement an equivalent cache in Go. Rationale: under the hook-completeness contract, a cache hit always serves exactly the bytes a fresh recompute would serve (identical body/status/headers); the cache's only observable effect is timing, which is a non-compatibility surface per CONTRACT.md. Computing responses fresh in Go is observably equivalent in every state-mutation scenario and does not reproduce upstream's own stale-on-missed-hook edges (which would be bug-reproduction). Recorded in `cap-route-r016.json` exceptions, not silently omitted.

## Architecture review
Implementing the LRU cache was considered and rejected: it adds invalidation plumbing across store write paths (the Go implementation has no Sequelize hook equivalent), creates real stale-response risk, and would be the only source of a difference — a net compatibility regression. Fresh compute is the stdlib-first smallest design.
