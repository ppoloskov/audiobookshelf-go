## Contract review — accepted after corrections

The independent reviewer rejected the first gate: one binding per invariant plus
verified ledger flags could hide missing error/repeat/failure assertions. The
current gate requires executable canonical facets and separately reviewed,
source-backed required semantic tuples. It checks exact case/state combinations;
independent sets do not imply a missing combination. The required tuple review
cannot be generated by copying the available test plan. Every canonical invariant
and active facet must be accounted for. Broad sampled invariants still need
source/client decomposition and independent completeness review before closure.

A synthetic all-verified ledger with only a normal/initial binding now fails.
Removing this fix with a Go overlay reproduces the failure-seeking regression.
Unknown/skipped/omitted/empty/failed proof events are rejected. Proof is emitted
only after concrete assertions pass, and the emitting subtest must also pass.

Login checks were corrected to distinguish explicit null from omission and to
require the fixture listener's exact ID. An overlay accepting omissions/other IDs
fails both counterexample tests. Live upstream also corrected an inherited mapping
error: cookie Secure follows direct/forwarded request security. Both HTTPS and
HTTP variants now pass; no application behavior was changed to accommodate tests.

Actual pinned JavaScript executes directly, so an older compiled app cannot act
as the reference. Before/after digests include source/assets, owner contract and
architecture, canonical requirements, exact scenarios, Go source/modules, Node
executable and installation-lock metadata. Installed lock metadata is not a hash
of every dependency module; do not claim it is. Fixtures are copied byte-identically
before root-path rewriting. Rollback remains mandatory inside the machine after
Go proof, and the existing Docker rollback job is preserved.

The final report records machine health PASS, eight successful upstream assertion
records, **5,618 coverage gaps**, identical before/after inputs, upstream PARTIAL
and Go BLOCKED. The command exits nonzero. Gaps include overlapping missing
bindings/facets/reviews; this count is not a feature denominator or a percentage.
Whole-source line/branch percentages remain unavailable; raw V8 is not proof.

## Craft and lifecycle review — accepted

The implementation uses Go standard facilities and existing dependencies, one
canonical feature register, no scenario language and no application framework.
The Python scanner/map and tests were removed after identity-checked .mjs ports.

The coordinator owns isolated subprocess groups, cancellation, termination,
reaping and logs. A non-race test exposed a cleanup signal refusal after children
had stopped. Cleanup now suppresses a refused signal only when a bounded native
process snapshot establishes no live members. Empty/malformed snapshots and live
members fail closed. Descendant cleanup passes ten repeated runs and the full
machine run; targeted race tests pass. Final independent review accepted this
cleanup and the contract/architecture input-digest additions.
