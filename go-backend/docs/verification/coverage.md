# Coverage matrix: upstream TS v2.37.2 vs Go rewrite

Generated by build_coverage.py / events.py / mobile.py in this directory from a frozen `git archive HEAD` (go-backend/) and the upstream sources in server/. Run results come from this session (2026-11-13).

## Method and limits

- Upstream routes: every `router.<verb>(` literal in server/routers/ApiRouter.js (mounted /api), PublicRouter.js (/public), HlsRouter.js (/hls), the auth routes of server/Auth.js, and the feed/init/status/ping/healthcheck routes of server/Server.js: **223** method+path rows. Not counted: the regex cache middleware (`GET /^\/libraries/`), the SPA fallback routes, static files, `router.all(*)`, and the `/socket.io` transport.
- Go routes: every `"METHOD /path"` literal passed to a mux in non-test code under internal/ (plus the two loops that build tags/genres and feeds patterns, expanded by hand). Present in Go = some Go pattern matches the upstream path with the same method (Go `{x}` wildcards match upstream `:x` and also upstream literals; those are listed under "wildcard matches"). This is a static check, not a request to a running server.
- "Differential" = a TS-vs-Go live run compares the two servers (replacement-trial steps with exact method+path; cases of tools/parity/cases/core.json with exact method+path). Evidence from text mentions in other differential scripts (scan-trial, acl/cascades/oidc/steps) is matched by path only, method unverified, and kept in its own class.
- "Recorded TS shape" = contracts/shapes/*.json, recorded once from TS v2.37.2 (2026-11-03), checked by `go test ./internal/contracttest` as status + content-type + type skeleton (+ Socket.IO event names/shape). It is a comparison against TS output, but of types only, not values.
- A route counts as exercised if at least one step requests it. Columns rt_success/ct_success say whether any such step got a status below 400 from TS (the success path); 7 routes classed as differential have no success-path step anywhere (listed below).
- Go package tests (internal/<pkg>/*_test.go) are matched by path literal text, method unverified.
