## Intentional boundaries and no-op behavior

- Preserve M11: Go refreshes or revokes active socket grants when users change; this is an intentional fail-closed security difference recorded in `docs/SIMPLIFICATION.md`.
- Keep stricter Go progress/library access checks unless an owner decision changes the security contract.
- No schema migrations or startup DB cleanup. TS-proven UUID playback-stream cleanup runs only at process startup; do not broaden it to runtime replacement/restore or other filesystem paths without lifecycle evidence.
- Preserve backup/restore and user-facing flows. Restore is a persisted-data compatibility boundary, not an optimization opportunity.
- Scan HTTP acceptance is asynchronous; tests wait for task/database state. Retry and repeated no-op behavior are asserted separately from first mutation events.
